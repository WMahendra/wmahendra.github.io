# University logos

Drop the official logo files here to have them appear in the Education section
of `/profile/`. Expected filenames (`.png` or `.svg` both work):

- `university-of-twente.png`
- `lund-university.png`
- `universitas-gadjah-mada.png`

Nothing else needs changing. Each row shows its logo only when the file exists,
and while none are present the logo column collapses so the dates stay flush
left. Logos are constrained by height (46 px desktop, 40 px mobile) inside a
112 px-wide box with `object-fit: contain`, so a wide wordmark and a square
crest end up with comparable visual weight and neither is stretched.

Use official assets only.
