    {% comment %} Light / dark toggle. It sits OUTSIDE #site-nav deliberately. jquery.greedy-navigation.js does `$('#site-nav button')`, which matches every button inside the nav, so a toggle placed in there is treated as the menu's own overflow button: it gets the plugin's "hidden" class and the overflow measurement goes wrong. Inline SVG rather than a Font Awesome icon, because this theme compiles only a subset of Font Awesome and fa-sun / fa-moon are not in it, so an icon-font button renders empty. Which icon shows is decided in CSS. The click handler is inline and self-contained rather than relying on the bundle, so the button works even if main.min.js fails. The id is site-theme-toggle, not theme-toggle, so the bundle does not also bind it - two handlers would toggle twice and cancel each other out. {% endcomment %}
