{% comment %} Reading progress for project pages. A line on the masthead's lower edge that extends to the right as the reader moves down the write-up. The element is created here rather than written into the masthead markup, so it exists only on pages that include this file, and so a reader with JavaScript off sees nothing missing. It is appended to .masthead, which the theme positions fixed at the top of the viewport. That makes the masthead the containing block, so the line sits exactly on its bottom border at any header height - including the taller wrapped header on narrow screens - without hard-coding an offset. Progress is measured across .page__content, not the whole document: the line completes where the text ends rather than at the bottom of the footer artwork. {% endcomment %}
